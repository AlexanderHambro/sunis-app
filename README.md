# Sunis — Find restaurants in the sun

Sunis is a Flask web application that shows which restaurants and bars with outdoor seating in Copenhagen are currently in sun or shadow. The result is based on the current position of the sun and building data such as building footprints and heights.

The app uses a local SQLite database and displays the results on an interactive Leaflet map.

---

## How it works

1. The restaurant and building data is loaded from CSV files in the `data/` folder.
2. The database is initialized by running `init_db.py`, which creates a local SQLite database called `sunis.db`.
3. The Flask backend uses SQL queries to retrieve restaurants and buildings from the database.
4. The current position of the sun is calculated using `pvlib` based on the current time and the coordinates of Copenhagen.
5. Building shadows are calculated geometrically using `shapely`, based on each building’s footprint and height.
6. For each restaurant, the app checks whether the restaurant’s location is inside a calculated shadow polygon.
7. The result is returned as JSON through the Flask API.
8. The frontend displays the restaurants on a Leaflet map. Restaurants in sun are shown with an orange marker, while restaurants in shadow are shown with a grey marker.

## Database initialization

The application uses a local SQLite database called `sunis.db`.

To initialize the database, run:

```bash
python init_db.py
```

This script creates the database tables and imports data from the CSV files in the `data/` folder.

The script creates the following tables:

| Table         | Description                            |
| ------------- | -------------------------------------- |
| `restaurants` | Stores restaurant and bar locations    |
| `buildings`   | Stores building footprints and heights |

The `restaurants` table is loaded from `data/restaurants.csv`.

The `buildings` table is loaded from `data/buildings.csv`.

---

## Running the application

After initializing the database, start the Flask app:

```bash
python app.py
```

Then open the application in a browser:

```text
http://127.0.0.1:5001
```
It takes some time for the everything to load 
---

## How to interact with the app

When the app is running, the user can:

- View restaurants and bars on an interactive map
- See whether each venue is currently in sun or shadow
- Click on a marker to see information about the venue
- Search for venues by name or address using regular expressions

---

## API endpoints

| Endpoint                       | Method | Description                                            |
| ------------------------------ | ------ | ------------------------------------------------------ |
| `/`                            | GET    | Shows the frontend map                                 |
| `/ping`                        | GET    | Checks whether the server is running                   |
| `/api/venues`                  | GET    | Returns restaurants with sun/shadow status             |
| `/api/venues?q=...`            | GET    | Searches restaurants using regular expression matching |

## Regular expression matching

The app supports regular expression matching through the search query parameter `q`.

Example:

```text
http://127.0.0.1:5001/api/venues?q=bar
```

The backend uses Python’s `re` module to match the search query against restaurant names and addresses.

## Notes

The app calculates shadows based on building footprints and building heights from the CSV data. The accuracy of the sun/shadow result therefore depends on the quality and completeness of the building data.

GeoDanmark's building footprints contain no height attribute, so we derived height from a second source. We spatially join each footprint to the Danish building register (BBR) and read its registered number of floors (byg054AntalEtager), estimating height as floors × 3 m on average — so a 4-storey building becomes 12 m. Buildings with no BBR match (≈61,000 of ~99,000, mostly small structures like sheds and garages) fall back to a default of 6 m. The floor-based figure is an estimate: BBR counts basements and attics separately, so tall-roofed buildings may be slightly underestimated."

The current version uses SQLite to make the project easy to run locally without requiring PostgreSQL or Docker.
